Scam & bad-listing filter

Every listing is checked before it can be recommended.

Price under 40% of the recent sold medianScam · skipped
Asks to pay or chat off-platform: LINE, WhatsApp, bank transfer, 直接取引Scam · skipped
New seller (< 3 months), < 5 reviews, or rating < 4.0Sketchy
ジャンク / 部品取り / 動作未確認 / "for parts" in the textSketchy + con
Vague description, stock photos (写真はイメージです)Sketchy
Same photo in another seller's listingSketchy
Already sold, ended or reservedDropped

2+ sketchy flags = scam. 40–70% of median is "a deal, check carefully": flagged only if something else is off. Rules first, then one AI check per listing for what rules can't see.

What the user sees

🚩 Skipped: ¥39,800, Jimoty. Price is 60% under the average, new account (<1 month), asks to talk on LINE.
  • Scams aren't hidden silently. You see why each one was rejected.
  • Unknown seller info is treated as unknown, not as guilty.
  • Soft issues stay visible as ⚠️ cons on real deals.

Built with

Three partner tools, one agent team.

AgentField

Orchestrates the scout, price and scam agents as separate nodes, draws the live workflow graph, and powers the approve-before-send pause.

Tavily

Search limited to each marketplace's domain, then extract to read the full listing page: price, condition, seller, photos.

Daytona

A sandbox with Chromium + Puppeteer, built from a snapshot, for marketplace pages that only render with JavaScript.
